# Relation entre MVDG et AXIOM

La MVDG constitue une application documentaire de la doctrine de gouvernance
portée par AXIOM.

| Doctrine AXIOM | Application MVDG |
|---|---|
| Mission bornée | Corpus et périmètre figés |
| Règles explicites | Référentiel écrit avant l’analyse |
| Validation indépendante | Contrôles séparés des constats produits |
| Traçabilité | Chaque constat est rattaché à une pièce |
| Interruption sûre | Une pièce absente produit une réserve, pas une invention |
| Décision humaine | Validation finale avant diffusion |

AXIOM gouverne l’exécution d’une mission. La MVDG gouverne l’établissement d’un
constat documentaire. Les deux refusent la production silencieuse d’une
conclusion invérifiable.
